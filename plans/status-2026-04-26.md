# Estado del Proyecto - 26 de Abril 2026

## Funcional

### Motor y Core
- Godot 4.6.2 compatible (sin C#/.NET)
- 7 autoloads: ScriptLoader, GameConfig, BuildingType, ResourceType, ColonyManager, ResourceManager, BuildingType
- ScriptLoader registra input actions en runtime (camera_move, ui_pause, ui_debug)
- Mundo procedural 200x200 tiles (16px cada uno) generado con FastNoiseLite

### Terreno
- 5 tipos: pasto (verde), agua (azul), montaña (gris), arena (amarillo), bosque (verde oscuro)
- Renderizado como ImageTexture estática con Sprite2D

### Beeps (4 iniciales)
- Círculos verdes (14px radio)
- Stats: salud, hambre, energía
- AI decision loop cada 0.5s:
  - Hambre >85% → busca comida
  - Hambre >65% → busca comida
  - Energía <25% → descansa
  - Colonia sin comida → busca comida
  - Colonia poca comida → recolecta
  - Default → vaga
- Movimiento: move_and_slide a 60px/s

### Recursos (50 iniciales)
- 3 tipos: comida (verde), madera (marrón), piedra (gris)
- Regeneración progresiva por tipo
- Spawn periódico cada 25s (max 60 en mapa)

### Sistemas
- **ColonyManager**: tracking de población, felicidad, salud, orden social
- **ResourceManager**: almacén de comida/madera/piedra con max values
- **DecisionSystem**: eventos cada 45s con 35s para responder
- **ReproductionSystem**: chequea cada 90s, cooldown 120s
- **SpawnManager**: gestiona beeps y recursos, posiciones válidas
- **Building system**: Shelter con construcción progresiva, curación

### Cámara
- Zoom inicial 0.5 (vista amplia)
- Movimiento WASD/flechas
- Zoom con scroll

### UI
- Debug console (F1): muestra stats en tiempo real
- Decision panel: eventos con timer bar y opciones

## No funcional / Pendiente

- Texturas: solo placeholders geométricos (_draw circles, ImageTerrain)
- AnimatedSprite2D: sin texturas (errores benignos)

## Completado (27 abril)

- **TileMap con TileSet**: reemplaza Sprite2D+ImageTexture por TileMap nativo con 5 tiles (16x16) generados por código con ruido para variación visual
- **Pathfinding A***: implementado en `scripts/core/pathfinding.gd` con octile heuristic y waypoint skipping
- **Shelter visual**: _draw con forma de casa, techo triangular, puerta, contador de ocupantes
- **Game Over / Victory**: overlay centrado con stats finales, tiempo jugado, botón reiniciar
- **Menú inicial**: overlay con título "CIVILISIM", botón "Iniciar Colonia", controles. Estado MENU en GameState. La simulación no arranca hasta que el jugador presiona el botón. Reiniciar recarga la escena y muestra el menú de nuevo

## Archivos clave
- `scenes/main/Main.gd`: entry point, instancia world dinámicamente
- `scenes/world/World.gd`: terreno, spawn, gestión de recursos
- `scenes/beep/BeepAgent.gd`: movimiento, stats, AI loop
- `scripts/systems/`: ColonyManager, ResourceManager, DecisionSystem, etc.
- `scripts/data/`: GameConfig, ResourceType, BuildingType
